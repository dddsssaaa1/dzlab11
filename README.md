# Домашнее задание к работе 11

## Условие задачи (Вариант 11)

Создать структуру для хранения записи «Автомобиль».

Поля записи:
- марка автомобиля;
- производитель;
- тип;
- год выпуска;
- дата регистрации.

Организовать ввод трех значений структур. Выполнить обработку 3 переменных структурного типа: вывести сведения о машинах марки Ford, зарегистрированных до 2000 года.

Для даты используется единый формат «день месяц год», сравнение выполняется по году регистрации.

---

## 1. Алгоритм и блок-схема

### Алгоритм

1. Настроить локализацию для корректного отображения русскоязычных сообщений в консоли.
2. Описать структуру `Date` с полями день, месяц и год, а также структуру `Car` со всеми полями записи автомобиля, где дата регистрации имеет тип `Date`.
3. В цикле от 0 до 2 запросить у пользователя и считать данные для трёх записей: марку, производителя, тип, год выпуска и дату регистрации (день, месяц, год) функцией `input_car`.
4. Вызвать функцию обработки `process_cars`:
   - подсчитать записи, у которых марка равна `Ford` и год регистрации меньше 2000;
   - вывести количество найденных записей;
   - для каждой найденной записи вывести её сведения функцией `print_car`.
5. Завершить выполнение программы.
